# MY — Personal Portfolio

A modern, responsive personal portfolio built with React, Vite,
Tailwind CSS, and Node.js/Express.

## ✨ Features

- Responsive portfolio design
- Animated hero section
- About section
- Skills showcase
- Project cards
- Contact form
- Gmail email integration
- Interactive UI
- Responsive navigation
- Location section

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

### Backend
- Node.js
- Express.js
- Nodemailer
- Gmail SMTP
